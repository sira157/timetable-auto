# สไตล์หน้าตาเว็บ: ระบบจัดตารางสอนอัตโนมัติ (ให้ยึดตามนี้ทุกหน้า)

ใช้ React + TypeScript + Tailwind CSS v4 (ประกาศด้วย `@theme` และ `@utility` ในไฟล์ CSS หลัก) ทุกข้อความเป็นภาษาไทย

## 1. ฟอนต์และสีพื้นฐาน
- ฟอนต์: "Sarabun", "Noto Sans Thai", ui-sans-serif, system-ui, sans-serif
- line-height 1.55, ใช้ antialiased
- พื้นหลังทั้งหน้า: #f6f7fb (เทาอมฟ้าอ่อนมาก)
- สีตัวอักษรหลัก: slate-800
- สีหลักของแบรนด์: indigo-600 (#4f46e5), hover indigo-700 (#4338ca), อ่อน indigo-50 (#eef2ff), indigo-100 (#e0e7ff)
- สีโทนเน้นอื่น: violet-600 (ใช้คู่กับ indigo ในไล่สี), green (สำเร็จ), amber (เตือน), red (ผิดพลาด), slate (ข้อความรอง/เส้นขอบ)
- โฟกัสด้วยคีย์บอร์ด: outline 2px indigo-500, offset 2px, มุมโค้ง 0.5rem
- สีที่เลือกข้อความ (selection): indigo-100

## 2. ส่วนประกอบพื้นฐาน (utility classes)
- **card:** มุมโค้ง rounded-2xl, เส้นขอบ slate-200 โปร่งเล็กน้อย, พื้นขาว, padding 20px, เงาบางมาก (`0 1px 2px rgba(15,23,42,.04)`)
- **btn (ฐาน):** inline-flex, ความสูงต่ำสุด 40px, มุมโค้ง rounded-xl, ตัวอักษร 14px medium, มีเอฟเฟกต์กดย่อ (scale 0.98), ปิดใช้งานเป็นจางลง 50%
  - **btn-primary:** พื้นอินดิโก-600 ตัวอักษรขาว มีเงาอินดิโกจาง hover เป็นอินดิโก-700
  - **btn-ghost:** พื้นขาว เส้นขอบ slate-300 ตัวอักษร slate-700 hover พื้น slate-50 และเส้นขอบเข้มขึ้น
  - **btn-danger:** พื้นขาว เส้นขอบแดงอ่อน ตัวอักษรแดง hover พื้นแดงอ่อน
- **input:** สูงต่ำสุด 40px, มุมโค้ง rounded-xl, เส้นขอบ slate-300, padding 12px/8px, placeholder slate-400; hover เส้นขอบเข้มขึ้น; focus เส้นขอบอินดิโก-500 + วงแหวนอินดิโก-100 หนา 4px; disabled พื้น slate-50
- **label:** ตัวอักษร 14px medium สี slate-600 อยู่บนฟิลด์ เว้นล่าง 4px
- **ตาราง:** หัวตารางพื้น slate-50 ตัวหนา 600 สี slate-500; แถวที่ hover พื้นอินดิโก-50 โปร่ง 55%
- **Scrollbar:** บาง สี slate-300
- **Badge (ป้ายสถานะ):** มุมโคนกลม (pill), เส้นขอบบาง, ตัวอักษร 12px:
  - ผ่าน/พร้อม: เขียว (พื้น green-50, ตัว green-700)
  - เตือน: เหลืองอำพัน (amber)
  - ผิดพลาด: แดง
  - ซ้ำ/ไม่ใช้: เทา, นำออกแล้วมีขีดฆ่า
  - รอยืนยัน/ประเภทไม่รู้จัก: อินดิโก

## 3. โครงหน้า (Layout)
- **เดสก์ท็อป (md ขึ้นไป):** แถบซ้ายกว้าง 240px ติดหน้าจอ (sticky, เลื่อนภายในได้) พื้นขาว เส้นขอบขวา slate-200; ด้านขวาเป็นพื้นที่เนื้อหา
- **มือถือ:** แถบซ้ายซ่อนอยู่ กดปุ่ม ☰ ที่หัวด้านบนเพื่อเปิดเมนูแนวตั้งด้านบนเนื้อหา; กดลิงก์แล้วปิดเมนูอัตโนมัติ
- **หัวด้านบน (header):** ติดด้านบน (sticky) พื้นขาวโปร่ง 80% + blur, เส้นขอบล่าง, ชิดขวามีเมนูผู้ใช้
- **เนื้อหา:** กว้างสูงสุด 1152px (max-w-6xl) จัดกึ่งกลาง padding 16px บนมือถือ / 32px บนเดสก์ท็อป, ระยะบน-ล่าง 24px ยกเว้นหน้าตารางสอนใช้ความกว้างเต็มพื้นที่

### 3.1 แถบเมนูซ้าย (ลำดับจากบนลงล่าง)
1. **โลโก้:** SVG (`LogoMark` ใน `components/Illustrations.tsx`) ขนาด 36–38px กล่องมุมโค้ง พื้นไล่สีจาก indigo-500 ไป violet-600 ข้างในเป็นปฏิทินสีขาวที่มีช่องตารางสี (ฟ้า เขียว อินดิโก เหลือง) และวงกลมเขียวมีเครื่องหมายถูก มีเงาอินดิโกจาง ใช้เป็นไอคอนแท็บเบราว์เซอร์ด้วย; ข้อความ "ระบบจัดตารางสอน" (ตัวหนา 15px slate-800) และบรรทัดรอง "อัตโนมัติ" (12px indigo-600)
2. **หน้าแรก** (ไอคอนบ้าน)
3. **ขั้นตอนการทำงาน** (หัวข้อเล็กสี slate-400) มี 5 รายการ เรียงตามลำดับ มีตัวเลขกำกับด้านขวาสีจาง:
   - นำเข้าข้อมูล (ไอคอนลูกศรลง) 1
   - ตรวจสอบข้อมูล (ไอคอนเครื่องหมายถูก) 2
   - จัดตาราง (ไอคอนสายฟ้า) 3
   - ตารางสอน (ไอคอนตาราง) 4
   - รายงาน / ส่งออก (ไอคอนเอกสาร) 5
4. **กลุ่มยุบ/ขยายได้** (หัวข้อเล็กตัวหนาสี slate-400 มีลูกศร ›  หมุนเมื่อเปิด):
   - **ข้อมูลพื้นฐาน:** อาจารย์, รายวิชา, กลุ่มเรียน, ห้องเรียน, อาคาร, เรียนรวม, สอนร่วม, เวลาที่ไม่ว่าง, ข้อมูลไม่ลงทะเบียน
   - **ระบบ:** ตั้งค่าเงื่อนไข, บัญชีผู้ใช้, สำรองและล้างข้อมูล, ประวัติการแก้ไข, ประวัติการประมวลผล
- **รายการเมนู:** ตัวอักษร 14px, มุมโค้ง, padding 10px/8px. ที่เลือกอยู่: พื้นอินดิโก-50, ตัวหนา อินดิโก-700, มีแถบเส้นซ้ายอินดิโกหนา 3px. ที่ยังไม่เลือก: slate-600, hover พื้น slate-100
- **ไอคอนในรายการหลัก:** กล่องขนาด 28px มุมโค้ง พื้น slate-100 ไอคอนเส้น slate-500; ที่เลือกอยู่ กล่องเป็นอินดิโกเข้มตัวขาว
- **รายการในกลุ่มย่อย:** ซ้ายเยื้อง 16px ไม่มีไอคอน

### 3.2 หน้านำเข้าข้อมูลและหน้ากรอกข้อมูล
- หัวหน้านำเข้าข้อมูลมีปุ่มหลัก "กรอกข้อมูล" (ไอคอนดินสอ) ไปหน้า `/import/manual` และมีการ์ด "กรอกข้อมูลบนเว็บ" ในคอลัมน์ไฟล์ที่นำเข้าได้
- หน้ากรอกข้อมูลมีแท็บ ชั้นปีที่ N / ฝ่ายบริหาร / สถานที่เรียน ตามชีตของไฟล์ Excel ข้อมูลหลักสูตร; แต่ละกลุ่มเรียนเป็นการ์ด มีคอลัมน์ ที่ | รหัสวิชา | ชื่อรายวิชา | อาจารย์ผู้สอน | สถานที่ที่ใช้ | หน่วยกิต | กลุ่มวิชา บนมือถือเรียงเป็นฟอร์มแนวตั้ง
- วิชาในกลุ่มเลือกเดียวกันแสดงเยื้องพร้อมเส้นซ้ายสีฟ้า (sky-300) และลูกศร ↳
- แถบบันทึกติดด้านล่าง แสดงป้าย "ยังไม่บันทึก" และช่องยืนยันการแทนที่ข้อมูลเดิม

## 4. หน้าแรก (Dashboard)
- **แบนเนอร์ใหญ่บนสุด:** พื้นไล่สีจาก indigo-600 ไป violet-600, มุมโค้ง 16px, เงาบาง, ตัวอักษรขาว
  - บรรทัดเล็กต้อนรับ "สวัสดี {ชื่อ}" หรือ "ยินดีต้อนรับ" (สีอินดิโก-100)
  - หัวเรื่อง "ระบบจัดตารางสอนอัตโนมัติ" ตัวหนา 24px (บนจอใหญ่ 30px)
  - คำอธิบายสั้น ๆ สีอินดิโก-100
  - กล่องโปร่งแสงขวา (พื้นขาว 10%, blur) แสดง "ขั้นตอนถัดไป" + ชื่อขั้นตอน + ปุ่มสีขาวตัวอินดิโกตัวหนา มีลูกศร →
- **แถบแจ้งเตือน** (ถ้ามี): แดงอ่อนสำหรับการตั้งค่าเวลาไม่ถูกต้อง, เหลืองอ่อนสำหรับตารางที่ข้อมูลเปลี่ยนหลังจัด; กดได้ทั้งแถบ
- **การ์ดสถิติ 4 ใบ** (มือถือ 2 คอลัมน์ เดสก์ท็อป 4): กล่องไอคอนอินดิโก-50 + ป้าย + ตัวเลขตัวหนาใหญ่ (tabular-nums); ใบที่ไม่มีห้องแสดงคำเตือนเหลือง
- **แถว 2 ช่อง** (เดสก์ท็อป 5:2):
  - การ์ด "ตารางสอนปัจจุบัน" (กว้าง 3 ส่วน) พร้อมปุ่ม
  - การ์ด "ความพร้อมของข้อมูล" (กว้าง 2 ส่วน) มีแถบสัดส่วนสี่สี: เขียว (พร้อม), เหลืองอำพัน (ต้องตรวจ), แดง (ผิดพลาด), ม่วง (ไม่พบในทะเบียน); มีจุดสีนำหน้าแต่ละรายการ
- **แถวขั้นตอน 4 ใบ** (เดสก์ท็อป 4, มือถือ 2): ใบที่เป็น "ถัดไป" มีเส้นขอบอินดิโก-300 และวงแหวนอินดิโก-100; วงกลมเลข: เสร็จ = เขียวอ่อนพร้อมเครื่องหมาย ✓, ถัดไป = อินดิโกตัวขาว, อื่น ๆ = เทาอ่อน
- **ทางลัด 4 ใบ:** การ์ดมีไอคอนอีโมจิ หัวเรื่อง และคำอธิบายสั้น hover เส้นขอบอินดิโก-200
- **หน้าเริ่มต้น (ยังไม่มีข้อมูล):** หัวเรื่อง "เริ่มต้นใช้งาน — เลือกวิธีใส่ข้อมูล" และการ์ด 3 ใบ: ดาวน์โหลดแบบฟอร์ม / นำเข้าไฟล์ / กรอกบนเว็บ (ปุ่มหลักอินดิโก 1 ปุ่ม) พร้อมลิงก์ "ลองนำเข้าข้อมูลตัวอย่าง"

## 5. หน้าตารางสอน (ส่วนสำคัญที่สุด)
- การ์ดขาวมีหัวเรื่อง (ตัวหนา) และคำบรรยายรอง (สี slate-500) ขวาสุดเป็นข้อความเล็ก "X คาบ/สัปดาห์"
- แกนตั้ง = วัน (คอลัมน์ซ้ายกว้าง 80px ติดซ้ายตอนเลื่อน ตัวอักษรสีเข้ม)
- แกนนอน = คาบ 1–N หัวคอลัมน์ 2 บรรทัด: "คาบ N" (ตัวกลาง) และช่วงเวลา "08:00–09:00" (ตัวอ่อนสีจาง); หัวติดด้านบนตอนเลื่อน
- ต้องเห็นตารางเต็มโดยไม่ต้องเลื่อนแนวนอน: จอ md ขึ้นไป ตารางกว้างเท่าพื้นที่ (table-fixed ไม่มีความกว้างต่ำสุด) บนมือถือแสดงเป็นรายวัน (การ์ดละ 1 วัน เรียงคาบจากเช้าถึงเย็น คั่นด้วยแถบพักกลางวัน)
- มีปุ่ม "เต็มจอ" ดูตารางเต็มหน้าจอ (Fullscreen API) และ PDF ใช้แบบตารางเสมอ (ตอนสร้าง PDF ไม่ใช้ sticky และชื่อไฟล์แทน / ด้วย -)
- ช่องวิชาไม่แสดงคำกำกับ (ทฤษฎี) (ปฏิบัติ) (ทฤษฎี+ปฏิบัติ)
- มุมมองชั้นปี: วิชาเลือกที่เรียนเวลาเดียวกันเป็นกล่องเดียว แสดงเฉพาะป้าย "วิชาเลือก" ชื่อกลุ่มวิชาเลือก และหน่วยกิต (ไม่แสดงรายวิชาย่อย) และพักกลางวันเป็นแถบเดียวตลอดทุกวัน
- **ช่องวิชา (บล็อก):** ปุ่มเต็มช่อง มุมโค้ง 6px เส้นขอบบาง ความสูงต่ำสุด 64px ข้อความ 12px:
  - บรรทัดแรก: รหัสวิชาตัวหนา + ป้ายเล็กมุมโค้ง (เรียนรวมพื้นเขียวเข้มตัวขาว, สอนร่วมพื้นอินดิโกเข้มตัวขาว)
  - บรรทัดสอง: ชื่อวิชา (ตัดเหลือ 2 บรรทัด)
  - บรรทัดสาม: ครูหรือกลุ่ม (ตามมุมมอง) ตัดด้วย …
  - บรรทัดสี่: ห้อง หรือ กลุ่ม
- **ช่องกว้างตามจำนวนคาบ:** วิชาที่ยาวหลายคาบต่อเนื่องจะขยายข้ามคอลัมน์ (colSpan) เส้นแบ่งคอลัมน์ slate-100
- **หลายช่องพร้อมกัน (lanes):** วันเดียวกันที่มีกิจกรรมคู่ขนานจะแยกเป็นแถวย่อยภายในวันเดียวกัน แถวหลักของแต่ละวันคั่นด้วยเส้น slate-200
- **สีบล็อก:**
  - วิชาปกติ: พื้น sky-50, เส้น sky-200, ตัว sky-900
  - เรียนรวม: พื้น green-50, เส้น green-200, ตัว green-900
  - สอนร่วม: พื้น indigo-50, เส้น indigo-200, ตัว indigo-900
  - กิจกรรม: พื้น violet-50, เส้น violet-200, ตัว violet-800
  - ประชุม: พื้น slate-100, เส้น slate-300, ตัว slate-700
  - พักกลางวัน: พื้น amber-50, เส้น amber-200, ตัว amber-800
- **คำอธิบายสี (legend)** ใต้ตาราง: กล่องสี่เหลี่ยมเล็ก 12×20px + ชื่อ เรียงในแถว วิชาปกติ, เรียนรวม, สอนร่วม, กิจกรรม, ประชุม, พักกลางวัน; ถ้าไม่มีแถบพักในตาราง จะมีหมายเหตุ "ช่องว่างช่วงกลางวัน = เวลาพัก"
- ตารางจากมุมมอง ครู / กลุ่ม / ห้อง / อาคาร มีรูปแบบเดียวกันและเปลี่ยนเฉพาะข้อความในบล็อก

- PDF: ทุกตารางเริ่มหน้าใหม่ วันอยู่คอลัมน์ซ้าย ข้อความในบล็อกแสดงเต็ม ใต้ตารางมี "รายวิชาในตาราง" (ที่ / รหัสวิชา / ชื่อรายวิชา / หน่วยกิต / อาจารย์ผู้สอน หรือชั้นปี/กลุ่ม / สถานที่ที่ใช้ / วันและคาบ / คาบ/สัปดาห์) ถ้าไม่พอหน้าเดียวให้ขึ้นหน้าใหม่ และมีชื่อตารางรุ่นกับเวลาพิมพ์ท้ายหน้า

## 6. หน้าต่างโมดัล (Modal)
- ฉากหลังดำโปร่ง 40% ซ่อนตัว
- บนมือถือ: โมดัลติดล่าง มุมบนโค้ง 16px เต็มความกว้าง; บนจอกว้าง: อยู่กลาง มุมโค้งทุกด้าน กว้างสูงสุด 512px (กว้าง: 768px)
- หัวโมดัล: หัวเรื่องตัวหนา เส้นขอบล่าง ปุ่ม × ขวาสุด สีเทา
- ส่วนท้ายโมดัล: ปุ่มชิดขวา เส้นขอบบน
- กด Esc เพื่อปิด, คลิกนอกกรอบเพื่อปิด

## 7. ภาพประกอบ
- ภาพประกอบเป็น SVG ในตัว (`components/Illustrations.tsx`) ใช้สีชุดเดียวกับระบบ และต้องอธิบายการใช้งานได้ ไม่ใช่ตกแต่งอย่างเดียว
  - `TimetableArt`: ภาพตารางสอน (หน้าเข้าสู่ระบบ แบนเนอร์หน้าแรก)
  - `WorkbookArt`: ไฟล์ Excel ข้อมูลหลักสูตรพร้อมแท็บชีต (หน้านำเข้า หน้าเริ่มต้นใช้งาน)
  - `PipelineArt`: ขั้นตอนการจัดตาราง (หน้าจัดตาราง ปุ่มหลักชื่อ "จัดตาราง")
  - `Ring`: วงแหวนสัดส่วนชั่วโมงที่จัดได้ (การ์ดตารางสอนปัจจุบัน)

## 8. หลักการทั่วไป
- ไม่ใช้เงาแรง ใช้เส้นขอบบางและพื้นหลังอ่อนแทน
- มุมโค้งเป็นหลัก: การ์ด 16px, ปุ่มและฟิลด์ 12px, ป้ายและบล็อกเล็ก 6–8px
- ตัวเลขที่เปลี่ยนค่าใช้ tabular-nums
- ปุ่มทุกปุ่มมีขนาดแตะได้อย่างน้อย 40px
- สถานะเตือนด้วยสีและข้อความ ไม่ใช้สีอย่างเดียว
- ทั้งระบบเป็นธีมสว่างเท่านั้น
- ใช้ได้ทั้งคอมและมือถือ ไม่มีการเลื่อนแนวนอนทั้งหน้า ขอบซ้ายขวา 16px
