# ระบบจัดตารางสอนอัตโนมัติ

เว็บจัดตารางสอนอัตโนมัติตามเงื่อนไขของหลักสูตร (FastAPI + SQLite / React + TypeScript + Tailwind CSS v4)

กฎของระบบอยู่ใน `docs/` (อ่านก่อนแก้โค้ดที่เกี่ยวข้อง):
- `docs/scheduling-rules.md` เงื่อนไขการจัดตาราง
- `docs/style-guide.md` สไตล์หน้าเว็บ
- `docs/auth-rules.md` ระบบล็อกอินและสิทธิ์

## โครงสร้าง
| ส่วน | หน้าที่ |
|---|---|
| `backend/scheduler.py` | ตัวจัดตาราง: CP-SAT (Google OR-Tools) จัดวัน คาบ ห้องเรียน ห้องคอมพิวเตอร์ และโรงยิม/สนามพร้อมกัน โดยมีวิธีละโมบเป็นคำตอบตั้งต้นและตัวสำรอง |
| `backend/validate.py` | ตรวจตารางทุกคาบ แยกข้อผิดพลาด/คำเตือน และตรวจความพร้อมของข้อมูล |
| `backend/auth.py`, `security.py` | ล็อกอิน PBKDF2, โทเคน HMAC, ตัวป้องกัน API แบบ deny by default |
| `backend/api.py` | ข้อมูลพื้นฐาน, นำเข้า/ส่งออก, จัดตาราง, รายงาน, สำรองข้อมูล, ประวัติ |
| `backend/data_io.py` | รูปแบบไฟล์ Excel/JSON สำหรับนำเข้าและแบบฟอร์ม |
| `backend/default_settings.json` | ค่าเริ่มต้นของเวลาเรียนและเงื่อนไข (แก้ได้ในหน้า "ตั้งค่าเงื่อนไข") |
| `sample-data/sample.json` | ข้อมูลตัวอย่าง (สมมติ) — ข้อมูลจริงให้นำเข้าผ่านหน้าเว็บ ไม่ฝังในโค้ด |
| `frontend/` | หน้าเว็บ React |
| `tests/` | ทดสอบระบบล็อกอิน/สิทธิ์ และกฎการจัดตาราง |

## รันในเครื่อง
```bash
pip install -r requirements-dev.txt
cd frontend && npm install && npm run build && cd ..
uvicorn backend.main:app --reload
```
เปิด http://127.0.0.1:8000 แล้วเข้าสู่ระบบด้วย `admin` / รหัสจาก `TIMETABLE_ADMIN_PASSWORD` (ถ้าไม่ได้ตั้ง = `admin1234`) ระบบจะบังคับให้เปลี่ยนรหัสผ่านทันที

พัฒนาหน้าเว็บแบบโหลดใหม่อัตโนมัติ: รัน backend ตามด้านบน แล้วรัน `npm run dev` ในโฟลเดอร์ `frontend` (เปิด http://localhost:5173)

ทดสอบ: `python -m pytest -q tests`

## การใช้งาน
1. **นำเข้า** — Excel (.xlsx), CSV (หลายไฟล์หรือ .zip) หรือ JSON · มีแบบฟอร์มและชุดตัวอย่าง เล็ก/กลาง/ใหญ่ (`sample-data/`)
2. **ตรวจข้อมูล** — แก้รายการสีแดง/ม่วงก่อน
3. **คำนวณ** — CP-SAT แสดงความคืบหน้า กดยกเลิก/ลองใหม่ได้
4. **ตรวจผล** — ดูตามกลุ่ม อาจารย์ ห้อง อาคาร · ลากวิชาไปช่องสีเขียวเพื่อย้าย · กดวิชาเพื่อล็อก
5. **ส่งออก** — PDF, Excel (ตารางแบบตาราง) และ CSV

สร้างชุดตัวอย่างใหม่: `python sample-data/generate_samples.py`

## Deploy บน Render (แผนฟรี)
1. Push โค้ดขึ้น GitHub
2. ที่ Render เลือก New → Blueprint แล้วเลือก repo นี้ (อ่าน `render.yaml` ซึ่ง build ทั้ง Python และหน้าเว็บ)
3. ใส่ค่า `TIMETABLE_ADMIN_PASSWORD` ก่อนกด Apply และห้ามตั้ง `TIMETABLE_AUTH_DISABLED`
4. เข้าสู่ระบบครั้งแรกแล้วเปลี่ยนรหัสผ่านผู้ดูแลทันที

## ข้อจำกัดของแผนฟรี
- บริการจะ sleep หลังไม่มีคนใช้ประมาณ 15 นาที เปิดครั้งแรกจะช้า ราว 30–60 วินาที
- ระบบไฟล์เป็นแบบชั่วคราว ข้อมูลใน SQLite จะหายเมื่อ redeploy หรือรีสตาร์ต
  ให้ใช้หน้า "สำรองและล้างข้อมูล" ดาวน์โหลดไฟล์สำรองเก็บไว้ จนกว่าจะย้ายไปใช้ disk ถาวรหรือฐานข้อมูลภายนอก
